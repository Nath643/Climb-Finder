# Climb finder

A full-stack web app for discovering and tracking climbing locations

## Tech Stack

- Frontend: vanilla javascript
- Backend: Node.js / Express
- Database: MySQL

## Features

- User registration and login
- Database-backed user storage

## Setup

### 1. Clone repo

git clone <repo-url>

### 2. Install dependencies

npm install

### 3. Create .env file

Copy .env.example and fill in values

### 4. Run server

cd backend
npm run dev

## Database

Run the schema file in My SQL workbench

## Environment Variables

Create a `.env` file:

MYSQL_HOST=
MYSQL_USER=
MYSQL_PASSWORD=
MYSQL_DATABASE=
